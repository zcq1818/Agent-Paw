新增：桌宠认识并会操作 Paw 自己的全部功能；Mac 版

- 问它“你会啥 / 怎么用 / 在哪设置 / 快捷键是啥 / 怎么升级快”，它会先查自带的使用手册再回答，不瞎编
- 直接让它改自己：“搭话少一点”“晚上 11 点到 8 点别吵我”“换成小猫”“大一点”“换深色”，说完就生效。模型、密钥、电脑控制权限这些仍然只能你自己改
- 让它动手：“陪我专注 45 分钟”“不专注了”“跳个舞”“讲个笑话”“播一下新闻”“下班小结”“叫团队出来”“藏起来”
- 带你去页面：“带我去改快捷键 / 配模型 / 看技能”，直接打开工作台对应的页面
- 问状态：“我们几级了 / 还差多少升级 / 今天专注多久 / 你在忙啥”
- Mac 版：Release 里的 universal.dmg，Intel 和 Apple 芯片通用。第一次打开要在“系统设置 → 隐私与安全性”里点“仍要打开”
