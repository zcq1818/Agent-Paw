Paw 的第一个公开版本 🎉

- 5 种 3D 桌宠形态，会走动、打盹、跳舞，专注会让它成长升级
- 拖文件给桌宠：Word / Excel / PPT / PDF / 图片 / 代码都能读
- 下班小结、看你用的软件适时帮忙、操作电脑（动手前都会先问你）
- 自建 AI 团队成员，房间里多人讨论，讨论时团队会出现在桌面上
- Alt + Space 快速启动器，支持拼音搜索
- 数据全部保存在安装目录下的 data 文件夹
- 支持自动更新

第一次打开请在 设置 → 模型 里填上你的模型服务（兼容 OpenAI 接口即可）。
安装包暂未签名，如果 Windows 提示"已保护你的电脑"，点 更多信息 → 仍要运行。
